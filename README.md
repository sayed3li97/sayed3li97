I am a **Google Developer Expert** and engineering leader. Today I lead **Digital Application Platforms at Oman Housing Bank**, after 5+ years building in regulated fintech at BNP Paribas, Tamkeen, and ila Bank, where the apps I shipped crossed **2.5M+ downloads**. My focus now is the next chapter of banking: **on-device AI, generative UI, and agentic workflows** running inside apps that cannot afford to be slow, unsafe, or offline.

Beyond the bank, I founded and lead **[Flutter MENA](https://sayedalialkamel.com)**, the largest Flutter community across the Middle East and North Africa, and I teach on stages worldwide. <details>
<summary><b>Enable the contribution snake above (one-time setup)</b></summary>

<br />

The snake image is generated by a GitHub Action. Create the file
`.github/workflows/snake.yml` in your `sayed3li97/sayed3li97` repo with the content below,
then run the workflow once from the Actions tab. It will build the branch the image points to.

```yaml
name: generate snake
on:
  schedule:
    - cron: "0 0 * * *"
  workflow_dispatch:
permissions:
  contents: write
jobs:
  generate:
    runs-on: ubuntu-latest
    steps:
      - uses: Platane/snk@v3
        id: snake
        with:
          github_user_name: ${{ github.repository_owner }}
          outputs: |
            dist/github-snake-dark.svg?palette=github-dark&color_snake=00b4ff
      - uses: crazy-max/ghaction-github-pages@v4
        with:
          target_branch: output
          build_dir: dist
        env:
          GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}
```

Until you enable it, the snake image will show as broken. You can delete that one `<img>` block if you prefer not to use it.

</details>
